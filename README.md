# Plant Nursery Inventory Management System

A Laravel 12 application for administrator login, plant inventory CRUD, and filtered plant reports. It does not manage sales or customer transactions.

## Setup

1. Install PHP 8.2+, Composer, and a supported Laravel database.
2. Run `composer install`.
3. Copy `.env.example` to `.env`, configure the database, and run `php artisan key:generate`.
4. Run `php artisan migrate`.
5. Create the initial administrator from the project directory:

   ```sh
   php artisan tinker
   ```

   ```php
   App\Models\User::create([
       'name' => 'Nursery Administrator',
       'email' => 'admin@example.com',
       'username' => 'admin',
       'password' => 'replace-with-a-strong-password',
   ]);
   ```

6. Run `php artisan serve` and open `/login`.

The login accepts either the administrator's email address or username. There is intentionally no public registration route.

## Features

- Authenticated resource routes for adding, listing, viewing, editing, and deleting plants.
- Server-side validation for required fields and nonnegative numeric unit prices.
- Each plant belongs to the user who created it.
- Reports can be filtered by report type, category, and stock status.
- Excel-compatible UTF-8 CSV and PDF downloads use the same validated filters as the report page.

Run the test suite with `php artisan test`.
